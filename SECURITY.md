# Seguridad

Aviso: este proyecto es un prototipo. No ofrece garantías ni SLA; no lo uses con datos sensibles.

## Reportar una vulnerabilidad

Reporta de forma privada: usa "Report a vulnerability" (GitHub Security Advisories) en el repositorio, o escribe a danielfajasallo742@gmail.com. No abras issues públicos ni publiques detalles antes de que se corrija. Intentamos responder en unos días.

## Alcance

En alcance: el servidor (`server/`), el endpoint de voz `/voice`, `POST /session`, `/api/*` y el front. Fuera de alcance: servicios de terceros (datos.gov.co, Deepgram, DeepSeek, WhatsApp), denegación de servicio volumétrica y hallazgos sobre dependencias sin vector explotable.
