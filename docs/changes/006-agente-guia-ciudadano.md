## Motivo

El uso real (logs de Cloud Run 17:25–17:45 y pruebas del dueño) mostró que el agente funciona como buscador de entidades y no como guía del ciudadano curioso, y que el pipeline de voz propio (Flux + TTS + contexto firmado) pierde contexto, se corta y es difícil de sostener. El proyecto hermano `cosas/hackaton` ("¿Dónde me atienden?", agente Gabriela) resuelve la conversación de voz con Deepgram Voice Agent API y DeepSeek como `think`, una misión estrecha, herramientas con enums, coincidencia aproximada de municipios, presupuesto de tiempo con respaldo offline e historial en la sesión del agente; el dueño reporta que funciona muy bien. Esta versión reemplaza la propuesta anterior de 006 (agregados en SQLite con job programado), que no se aprobó.

## Decisión de alcance (para reducir riesgo con el límite de 20:18)

- **Voz** (y lo escrito o tocado mientras la voz está activa): una sesión de Deepgram Voice Agent por usuario; el texto entra con `InjectUserMessage`; el historial vive en la sesión.
- **Solo texto** (sin activar la voz): se mantiene `/api/chat` con el mismo agente, las mismas herramientas y la misma misión (eval:real 35/35 ya pasa), para no reescribir el contrato de texto ni sus pruebas bloqueadas.
- Las herramientas, la misión, el formato de pesos y el respaldo son **los mismos módulos** para ambos caminos.

## Contratos de interfaz (para QA y constructores)

- **Herramientas (T023)** — `server/agent/tools.ts`: `TOOL_DEFS` (definiciones JSON Schema con enums) y `runTool(name, args, ctx) → { data, cards, context?, note? }` para `gasto_total`, `gasto_por_categoria`, `top_entidades`, `top_contratistas`, `contratos_mayores`, `buscar_contratos`, `detalle_contrato`. Parámetros comunes: `municipio?`, `departamento?`, `entidad?` (nombre o NIT), `tema?`, `anio?` o `desde?/hasta?`, `limite?` (≤ 10). Errores sin lanzar: `{ data: { error: "servicio_no_disponible" | "sin_resultados" | "lugar_desconocido", sugerencias? } }`. `note` = instrucción breve inyectada para el modelo (p. ej. "di que se amplió al departamento").
- **Coincidencia aproximada** — `server/data/places.ts`: `matchPlace(texto) → { municipio?, departamento, alcance: "municipio"|"departamento" } | { sugerencias: string[] }` (tolera tildes y errores tipo STT: "Manisales" → Manizales); `matchEntity(texto, entidades)` igual para entidades.
- **Respaldo** — `server/fallback/snapshot.json.gz` generado por `npm run snapshot` (`scripts/snapshot.ts`), con `generatedAt`; `server/data/budget.ts`: 1 reintento, tope total de 6,5 s.
- **Misión (T024)** — `server/agent/mission.ts`: `MISSION_PROMPT` (misma misión para texto y voz).
- **Voz (T024)** — proxy en `/voice?token=` (se conservan `POST /session` y `verifyUpgrade`) hacia `DEEPGRAM_AGENT_URL` (por defecto `wss://agent.deepgram.com/v1/agent/converse`, sustituible en pruebas). `server/voice/agent.ts`: `buildSettings(env) → Settings` (listen nova-3 `es` con keyterms; think `{ provider: { type: "open_ai", model: "deepseek-flash", temperature: 0.2 }, endpoint: { url: <DEEPSEEK_BASE_URL>/chat/completions, headers: { authorization } }, prompt: MISSION_PROMPT, functions: TOOL_DEFS }`; speak `aura-2-celeste-es`; sin `greeting` de relleno); clave `DEEPSEEK_VOICE_API_KEY` o, si falta, `DEEPSEEK_API_KEY`. Del cliente se aceptan solo: audio binario (≤ 64 KB por trama), `{type:"KeepAlive"}`, `{type:"AskText", text}` (1–500 caracteres → `InjectUserMessage`).
